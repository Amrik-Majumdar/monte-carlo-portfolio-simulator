# Privacy Notes

Last updated: July 2026

This public repository should not contain private financial information.

## Data Not Included

Do not commit:

- brokerage exports
- account statements
- personal portfolio records
- tax documents
- API keys
- private spreadsheets or generated reports with personal holdings

## Local Use

If you use private financial data locally, keep it outside the repository and confirm that `.gitignore` excludes generated outputs before committing.
