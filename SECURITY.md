# Security Policy

Last updated: July 2026

This repository is a public educational simulation project. The main security risk is accidental publication of private financial data, credentials, or generated files.

## Reporting A Security Issue

Please report security concerns privately by email:

**majumdar.amrik@gmail.com**

Include the affected file, a short description, and steps to reproduce when applicable.

## Repository Safety Rules

- Do not publish private account data.
- Do not publish API keys or credentials.
- Use synthetic or clearly public-safe sample inputs.
- Review generated charts, reports, and logs before committing them.
